標準ストリームってのはfd(0,1,2)のことでpythonだとsys.stdinみたいなやつ
sys.stdout.flush()はバッファを強制的に吐き出す、pythonの出力はバッファリングされるからエラーを吐く前にflushすることで安全。stdoutとstderrは別々のバッファを持っている。
ターミナルで直接出力は行バッファ
fileやpipeにリダイレクトしている場合バッファがいっぱいになるかプログラム終了までため込む方式。stderrはバッファリングされない設計なので先に出て順序が逆転する
なので今回の実装は保険要素が強いけどやり得
print()は自動で\nって判定されて自動でflushしてくれるけど
print以外の関数だと\nの自動付与がついてないからそれに対してflushをしてる
