順序を比較する必要がある関数にだけ用意されている引数がKey
「lambda はどうコードを簡潔にするか」→ 1回しか使わない小さな変換に名前と定義の儀式が不要になる
「lambda vs def の使い分け」→ その場で渡して捨てるなら lambda、再利用する・複数行必要・名前が説明になるなら def。PEP 8 が f = lambda ... を非推奨にしている理由も添えられると強い
key= は「比較基準の関数」

クロージャの流れ
最初に呼び出したとき上の関数に引数を渡して上の関数は役目を終える、そしてそこに代入してある変数に対して中の関数と直接つなぐ関数オブジェクトを渡してる
関数オブジェクトなので変数（）みたいにかけてそしたらその引数が中の関数に対して引数を渡してることになる　

partial 関数オブジェクトを入れてその後に関数オブジェクトに対する引数を入れて行くイメージ
